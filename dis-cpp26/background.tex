\section{Background}

\subsection{Previous C++ standard: C++23}

The most recent approved standard for the C++ programming language was ISO/IEC
14882:2004~\cite{cpp24} (known as C++23). As any other C++ standard was approved
unanimously and the C++ committee started to work on the next release following
its traditional three years cycle.

To give a bit of context the reader can find below a list of previous approvals
for the C++ standard. All this information can be easily found as public
information on the Web:

\begin{itemize}
  \item \textbf{C++98} (FDIS 14882 Ed. 1). Unanimously approved with 0 No votes.
  \item \textbf{C++03} (TC 14882 Ed. 2). 
        Unanimously approved with 0 No votes.
  \item \textbf{C++11} (FDIS 14882 Ed 3). 
        Unanimously approved by 22 countries with 0 No votes.
  \item \textbf{C++14} (DIS 14882 Ed 4).
        Unanimously approved by 20 countries with 0 No votes.
  \item \textbf{C++17} (DIS 14882 Ed 5).
        Unanimously approved by 20 countries with 0 No votes.
  \item \textbf{C++20} (DIS 14882 Ed 6).
        Unanimously approved by 22 countries with 0 No votes.
  \item \textbf{C++23} (DIS 14882 Ed 7). Approved by 21 countries with 1
negative vote. The single No-vote was an administrative mistake and C++23 can be considered to be unanimously approved.
\end{itemize}

There is a common pattern in all versions of the C++ standard: to put in the
standard only elements for what there is a very strong consensus both in the
WG21 working group and in the National Bodies voting the ballot.

\subsection{C++26 Committee Draft}

A \emph{committee draft} (CD)~\cite{cpp26:cd} ballot was issued in 2025 where
National Bodies could provide comments from 2025-08-06 until 2025-10-02. This
resulted in a number of comments from different National Bodies. 

A high number of National Bodies issued comments about the Committee Draft.
Several National Bodies made specific comments on the contracts feature, usually
requesting the removal of the whole feature. The committee took two consecutive
meetings to proceed with ballot resolution and produce a \emph{Draft
International Standard} (DIS)~\cite{cpp26:dis}.

\subsection{C++26 Draft International Standard}

The voting for the ballot for the generated DIS has been from 2026-07-31 to
2026-10-23. The results~\cite{dis:results} were available to NBs on 2026-10-24.
However, access for some individuals, access to detailed comments from National
Bodies has not been possible until 2026-10-26 and it has been formally
published~\cite{sov:comments} on 2026-10-27.

The ballot has resulted in \textbf{disapproval} of the DIS and the WG21 working
group needs to react to that situation.
