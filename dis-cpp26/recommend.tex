\section{Recommendation}

We very strongly recommend that the contracts feature is removed from the DIS
and a new ballot is initiated as soon as possible. This will allow to deliver
Edition 8 of ISO/IEC 14882 almost in time with most of the features.

In parallel with that WG21 should start working in a really minimal contracts
solution for Edition 9 of ISO/IEC 14882 (hopefully C++29). That solution should
include only the set of features that can achieve a strong consensus both at the
WG21 working group and at the National Bodies level.
