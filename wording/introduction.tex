\section{Introduction}

After ballot for ISO/IEC 14882 DIS~\cite{cpp26:dis} and a proposal to remove
C++26 contracts~\cite{p4443r0}, lists the set of changes that should be applied
to the DIS to remove contracts.

As a convention in this paper all \stdremove{text to be removed} is marked with
red background and all the \stdadd{text to be added} is marked with green
background.
