\section{Modifications to clause 5 (Lexical conventions)}

The following modifications shall be applied to clause 5 (\emph{Lexical
conventions} [\texttt{lex}]):

In Table 4 (Identifiers with special meaning [\texttt{tab:lex.name.special}])
remove the following identifiers:

\begin{itemize}
  \item \stdremove{\texttt{pre}}
  \item \stdremove{\texttt{post}}
\end{itemize}


In Table 5 (Keywords [\texttt{tab:lex.key}]) remove the following keyword:

\begin{itemize}
  \item \stdremove{\texttt{contract\_assert}}
\end{itemize}
