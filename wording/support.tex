\section{Modifications to clause 17 (Language support library)}

The following modifications shall be applied to clause 17 (\emph{Language
support library} [\texttt{support}]):

\begin{modification}[{Modification of 17.1[support.general]/2}]
The following subclauses describe common type definitions used throughout the
library, characteristics of the predefined types, functions supporting start and
termination of a C++ program, support for dynamic memory management, support
for dynamic type identification, \stdremove{support for contract-violation
handling,}
support for exception processing, support for initializer lists, and other
runtime support, as summarized in Table 42.  
\end{modification}

\begin{modification}[{Modification of Table 42 [tab:support.summary]}]
Remove from Table 42 the following entry

\begin{itemize}

\item
\stdremove{17.10\qquad Contract-violation handling\qquad\texttt{<contracts>}}

\end{itemize}

\end{modification}

\begin{noted}
In clause 17.3.2[version.syn], \textbf{remove} from the code listing the following lines:

\ldots\\
\stdremove{\texttt{\#define \_\_cpp\_lib\_contracts    202502L // freestanding, also in
<contracts>}}\\
\ldots\\
\stdremove{\texttt{\#define
\_\_cpp\_lib\_replaceable\_contract\_violation\_handler  see below}}\\
\stdremove{\texttt{// freestanding, also in <contracts>}}\\
\ldots\\
\end{noted}



\begin{removal}[{17.3.2[version.syn]/5}]
\stdremove{The macro
\texttt{\_\_cpp\_lib\_replaceable\_contract\_violation\_handler} is defined to
the integer literal \texttt{202603L}
if the \emph{contract-violation} handler is replaceable, and to the integer
literal 0 otherwise (6.11.3).}
\end{removal}

\begin{removal}[{17.10[support.contract]}]
Section 17.10 (\emph{Contract-violation handling} [\texttt{support.contract}])
shall be \textbf{completely removed}.
\end{removal}
